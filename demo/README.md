# JARVIS Canonical Demo Project

This is a deterministic Python project used for end-to-end demonstrations of JARVIS's cross-application context continuity.

## Scenario
The file `main.py` contains a deliberate import error. The goal is to have JARVIS observe the error, find the documentation in the browser, and propose the fix in VS Code.
